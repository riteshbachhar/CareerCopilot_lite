Settings

Optional LLM-assisted JD cleanup. When enabled, a "Clean up JD ✨" button appears in the detail view that asks the LLM to reorganize the captured body into clean sections (Responsibilities, Requirements, Benefits…). Capture itself never calls the LLM. The LLM filters and reorganizes — it does not paraphrase or summarize.
Privacy: your API key is stored only in this browser (chrome.storage.local). Captured JD bodies are sent to Groq only when you click "Clean up JD ✨" on a row. Profile data is never sent.
